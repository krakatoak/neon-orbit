A pixel-art orbit-survival arcade game. Keep your satellite on the ring, catch yellow energy cells for score, and dodge the asteroids as the level rises. Built by an AI agent, in a single self-contained HTML5/Canvas game with no dependencies.

## Run it

```sh
python3 -m http.server 8000 --directory game
# open http://localhost:8000
```

Controls: left/right arrows (or A/D) to move your satellite around the ring.
